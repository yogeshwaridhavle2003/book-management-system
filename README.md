# 📚 Book Management System (React + MockAPI)

A modern React-based Book Management System that allows users to perform full CRUD operations (Create, Read, Update, Delete) using MockAPI.

## 🚀 Live Demo
https://your-vercel-link-here.vercel.app

---

## 📸 Project Overview

This application helps users manage book records efficiently with a clean and modern UI.

Users can:
- Add new books
- Update existing books
- Delete books
- Search books by title or author
- Filter books by genre

---

## ✨ Features

- 📖 Add Book (Create)
- ✏️ Edit Book (Update)
- 🗑️ Delete Book
- 🔍 Search by Title / Author
- 🎯 Filter by Genre
- 📡 MockAPI Integration (REST API)
- ⏳ Loading State Handling
- 📱 Responsive UI Design

---

## 🛠️ Tech Stack

- React JS
- Axios
- JavaScript (ES6+)
- CSS3
- MockAPI (Fake Backend)
- Vercel (Deployment)

## 📂 Project Structure
